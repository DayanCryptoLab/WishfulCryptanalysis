Challenge rules

All tracks use 128-bit AES blocks and the standard key schedule. The final retained round omits MixColumns.

1A–1C

Davies–Meyer

The message block is the AES key. Each compression output XORs in the prior chaining value.

  • 1A: One freely chosen IV, shared by both inputs.
  • 1B: One-block collision under the prescribed IV.
  • 1C: Two-block collision with different first-block chaining values.

2A–2B

Matyas–Meyer–Oseas

The chaining value is the AES key. Each compression output XORs in the message block.

  • 2A: One freely chosen IV, shared by both inputs.
  • 2B: A prescribed IV and equal-length inputs of one or two blocks. Two-block inputs have different first-block chaining values.

3A–3B

Single-key recovery

Recover the full AES-128 key within a chosen-plaintext budget.

  • 3A: Up to 234 chosen plaintexts.
  • 3B: Up to 16 chosen plaintexts.

Fixed IVs. ZERO-IV is all zeros. AES-CRUNCHY-v1 uses a public, challenge-specific IV.
