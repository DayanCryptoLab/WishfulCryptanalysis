The research

From a claim to a checkable result

Wishful Cryptanalysis studies how foundation models can contribute to cryptographic research. The report pairs agent-led exploration with independent verification, using reduced-round Keccak and AES-128 hashing challenges to examine which findings can be checked directly.

Each case fixes the target parameters and available compute. A concrete witness, such as a collision pair or preimage, lets a separate checker test the result against the stated instance.
